# ModelCraft 🧠

ModelForge is a personal ML training playground built for beginner-friendly experiments.
> Not for public reuse or commercial use. Contact for permission.

## Features
- Upload CSV and select features/targets
- Choose ML models (regression, classification, clustering)
- Train and visualize models (regression lines, decision boundaries, clusters)
- Compare model metrics
